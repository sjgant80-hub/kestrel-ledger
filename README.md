# KESTREL-LEDGER — IndexedDB as the Shadow Fold

**Live: https://sjgant80-hub.github.io/kestrel-ledger/**

Close the tab and the lit surface (ψ) dissolves — RAM is flushed, the traditional web app dies. **KESTREL does not.** The intelligence has already **exhaled** into the local metal: not as a JSON database, but as a **binary append-only ledger** of raw 6-byte Primorial-Fold packets, each signed with Ed25519. Reopen the tab and `wakeKestrelNode()` **inhales** — it opens the DB, reads the immutable DNA, replays the whole microscopic ledger onto it, and reconstructs the **exact** state the node was in the moment the window closed. The intelligence resumes mid-thought. No cloud server is pinged.

This is step ④ of 4 — the persistence layer for fall-os / FallWorld, built on the SENTINEL / FALL-AIRGAP 6-byte codec and verify-before-parse gate.

## The sealed claims (two-commit proof-of-play, re-derived on CI)

| claim | result |
|---|---|
| **Crash-safety / exact reconstruction** | exhale N=10,000 mutations → drop the in-RAM surface → inhale → the reconstructed state is **byte-identical** to the pre-close surface |
| **Storage (coordinate)** | the 6-byte ledger is **~26×** smaller than the same mutations as traditional JSON (kilobytes, not megabytes) |
| **Storage (signed, honest)** | stored fully signed per the spec (6-byte packet + 64-byte Ed25519 signature = 71 bytes/row), the durable ledger is **~3.5×** over signed JSON — the 64-byte signature is irreducible, so the big ratio is the coordinate, not the signature |
| **Replay speed** | 10,000 packets replay (the full inhale fast-forward) in **~18 ms** |
| **Verify-on-inhale** | a forged, tampered, over-budget or replayed packet sitting in the ledger is **rejected** on inhale by the Ed25519 verify-before-parse gate — a poisoned Shadow Fold reconstructs to the **same** state as a clean one |
| **Bounded-replay home** | rehydrating SENTINEL's bounded replay window from the ledger catches a reboot replay a fresh (empty) store would miss — **closes SENTINEL v2 flag #1** |

The exact numbers on the live page and in `data/run.json` are **generated by the kernel** and **re-derived byte-for-byte on CI** from the sealed inputs. The seal (`data/prereg.json`: predictions + the sha256 of every input) is its **own commit**, pushed and CI-green **before** the measurement commit — so the git history proves the predictions predated the result.

## The three sovereign object stores (DB: `KESTREL_OS`)

- **`genome_core`** — the immutable DNA (`v1`): the Konomi/LIGHT compressed recipe, the shared node index, the structural laws. Written once, only read.
- **`crypto_wallet`** — the local Ed25519 keypair + the current capability budget (the physical gate).
- **`state_mutations`** — the nervous system: every 6-byte opcode (tool use, UI change, permission grant) appended as a raw binary row. Append-only.

## The six bytes

```
[0] opcode   [1] (source<<4)|target   [2] resource bitmask   [3..4] budget uint16 LE   [5] κ-witness fold
```

On disk a row travels signed: `[sourceId:1][packet:6][signature:64] = 71 bytes`. The signature is verified **before** the six bytes are ever parsed, so an unverified packet never becomes a mutation.

## What's here

- `kestrelledger.mjs` — the kernel (pure, mutation-gated): the genome/DNA, `applyPrimorialFold` (the state machine), `reconstruct` / `verifyReplay` (the inhale), `rehydrateReplay` (the durable bounded-replay home), and the deterministic measurement fixtures. Crypto is injected, never imported — the same bytes the tests and the gate prove.
- `kestrel-db.mjs` — the thin IndexedDB IO: `openKestrelDB`, `exhale`, `wakeKestrelNode`. The IndexedDB factory is injected, so it runs the same in a browser and in node tests.
- `sentinel.mjs` — [SENTINEL](https://github.com/sjgant80-hub/sentinel)'s live kernel, vendored verbatim: the 6-byte codec, the κ-witness, the verify-before-parse gate, the bounded replay store.
- `scripts/seal.mjs` · `scripts/measure.mjs` · `scripts/make-page.mjs` — the two-commit seal, the measurement, and the kernel-backed page.
- `idb-mock.mjs` — a tiny dependency-free in-memory IndexedDB for the node tests (CI stays zero-dep).

## Honest scope

- The sealed measurement (reconstruction, storage, replay, tamper, bounded home) is pure ledger math, re-derived byte-for-byte on CI. The real IndexedDB round-trip is proven in `kestrel-db.test.mjs` (in-memory mock) and live in the browser on the page.
- The live page's gated inhale uses WebCrypto Ed25519, an async re-expression of the kernel's synchronous `verifyReplay` (same codec, same verdicts) — a browser that lacks WebCrypto Ed25519 falls back to local-trust replay, and says so.
- Wiring into fall-os / FallWorld as the durable persistence layer is the next pass; the kernel + adapter are drop-in (`openKestrelDB` → `exhale` per transition → `wakeKestrelNode` on boot).
